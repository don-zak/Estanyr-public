# Public / Private Security Boundary

The public repository is a publication surface.

It must never become a mirror, fork, export, or history-rewrite of the
private CGT repository.

Material may cross from PRIVATE to PUBLIC only after an explicit
publication review.

## Allowed

- public API contracts
- abstract architecture
- non-sensitive schemas
- synthetic examples
- selected evidence terminology

## Forbidden

- reconstruction-capable proprietary algorithms
- exact private experiment definitions
- private provenance artifacts
- unpublished results
- secrets
- cryptographic keys
